KNX IoT
#######

`KNX IoT`_ extends the widely adopted `KNX`_ building automation standard, which traditionally runs over a wired twisted-pair bus.
The `KNX IoT Point API`_ is an open-source implementation provided by the KNX Association and it specifies how KNX devices communicate over IPv6 networks.
The current solution supports KNX IoT over Thread, bringing low-power mesh networking to KNX sensors and actuators.

Support for the KNX IoT is provided through the `KNX IoT Add-on`_ for nRF Connect SDK.
For source code, refer to the `ncs-knx-iot add-on repository`_.
