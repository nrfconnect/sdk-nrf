nRF Connect SDK add-on integrations
###################################

|NCS| add-ons are supplementary components, that include: applications, libraries, drivers, and protocol stack. 
They are maintained in separate repositories and distributed outside the main |NCS| tree.
Add-ons extend the SDK in specific domains (for example, Matter, Zigbee, or Edge AI) while tracking their own release cadence and documentation.

The `nRF Connect SDK Add-ons`_ index lists publicly available add-ons that you can browse, filter, and add to a west workspace.
Use it when you need the full catalog of supported add-ons and compatibility information for a given |NCS| version.
