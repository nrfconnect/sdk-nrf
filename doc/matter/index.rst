Matter Add-on
#############

The Matter Add-on is a collection of Matter samples and applications built on top of the nRF Connect SDK.
Documentation is available on the `Matter Add-on`_ website.
In addition to the Add-on documentation, this documentation set includes selected pages from the `Matter <https://github.com/nrfconnect/sdk-connectedhomeip>`_ repository fork, with a focus on the nRF Connect platform in Matter.

Read the :ref:`Migration guide <migration_sdk_nrf_to_ncs_matter>` to learn how to migrate your project from |NCS| Matter to the Matter Add-on.
