.. ncs-sample::
   :title: nRF91x1: DECT NR+ IPv6 tethering

   The DECT NR+ IPv6 tethering sample shows how to expose a DECT NR+ uplink to a wired Ethernet host without SLAAC, using IPv6 Router Advertisements and a minimal DHCPv6 server.
   It uses the :ref:`lib_dect_tethering` library.

   .. note::
      The current implementation is :ref:`experimental <software_maturity>`.

   See the subpages for detailed documentation on the sample and OS-specific usage.
